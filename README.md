# Hybrid RSA-AES medical image encryption: experiments

Code and raw results for the paper *"Enhancing Medical Image Reconstruction Using RSA-OAEP and Hybrid RSA-AES Encryption"* (revised version).

The script evaluates an authenticated hybrid pipeline (AES-128-GCM, or AES-128-CBC + HMAC-SHA256, with the session key wrapped by RSA-2048-OAEP and an optional RSA-PSS signature) and compares it with pure-RSA baselines. It produces every table of the paper.

## Contents

| File / folder | Description |
|---|---|
| `secure_medimg_experiments.py` | All experiments: round trip, entropy / chi-square / correlation, repeated timing, pure-RSA baselines, NPCR/UACI, key sensitivity, tamper and forgery tests, corruption and recovery |
| `make_figures.py` | Rebuilds Figures 1 and 2 from the saved images |
| `requirements.txt` | Python packages |
| `results_native/` | Run on 100 images at their native size (entropy, correlation, diffusion, key sensitivity, tamper, recovery) |
| `results_timing_415x720/` | Timing and RSA baselines on images resized to 415x720 |
| `*/environment.json` | Software versions, hardware, arguments, random seed, and the SHA-256 of every image file used |
| `*/paper_tables.md` | Summary tables generated by the script |
| `*/*.csv` | Raw per-image / per-repetition results |

## Data

The images are **not** redistributed here. They come from the public Kaggle dataset
[Digital Knee X-ray Images](https://www.kaggle.com/datasets/orvile/digital-knee-x-ray-images)
(files labelled `NormalG0`). Download it from Kaggle and check its licence and terms of use.
The exact files used are listed with their SHA-256 hashes in `results_native/environment.json`.

## Reproducing the results (Google Colab or any Python 3 machine)

```bash
pip install -r requirements.txt

# 1) native-size run: 100 images, seed 42  (about 15-45 min)
python secure_medimg_experiments.py --data_dir /path/to/knee_images --max_images 100 --out_dir results_native

# 2) timing and RSA baselines at 415x720, including direct full-image pixel-wise RSA encryption
python secure_medimg_experiments.py --data_dir /path/to/knee_images --max_images 5 --resize 415x720 \
    --skip basic,diffusion,keysens,recovery,tamper --rsa_pixel_full_enc --out_dir results_timing_415x720

# 3) figures
python make_figures.py --results results_native --out figures
```

`python secure_medimg_experiments.py --synthetic 3 --quick --out_dir smoke` runs a short smoke test on synthetic images (the numbers from this test must not be reported).

## Notes

* The numpy random seed (`--seed`, default 42) controls image selection, masks, bit positions and sample positions.
  Encryption keys, IVs and nonces come from the operating-system CSPRNG and are deliberately not seeded.
  A fixed key/IV (and GCM nonce reuse) is used only inside the NPCR/UACI diffusion test.
* Timings depend on the hardware. The reported ones were obtained on a shared Google Colab virtual machine
  (see `environment.json`) and vary by 25-40% between runs.
* The decryption time of pixel-wise textbook RSA for a full image is extrapolated from a small sample; all other
  baseline timings are measured directly.
